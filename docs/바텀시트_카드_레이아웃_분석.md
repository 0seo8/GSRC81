# 바텀시트 카드 레이아웃 분석

## 📸 원하는 디자인 (img.png 기준)

### 왼쪽 - 1개 카드

- 노란색 카드 1개만 표시
- 바텀시트 바닥에 배치
- 전체 둥근 모서리 (borderRadius: 45px)
- 높이: 130px (8.125rem)
- **상태**: ✅ 정상

### 중간 - 2개 카드

- **노란색 카드**: 앞에 보임 (zIndex: 2), 아래 위치 (bottom: 0)
- **회색 카드**: 뒤에 보임 (zIndex: 1), 위 위치 (bottom: 5.4375rem / 87px)
- 카드가 겹쳐진 스택 형태
- **zIndex 배치**: ✅ 정상
- **바텀시트 높이**: ✅ 60vh로 해결 완료

### 오른쪽 - 3개 이상 카드

- 첫 번째 카드: bottom -5rem (숨김)
- 두 번째 카드: bottom 0 (기준점)
- 세 번째 이상: 8.875rem부터 5.4375rem씩 간격
- 스크롤 가능
- **상태**: ✅ 정상

## ✅ 최종 적용 방안

### **채택: vh(바텀시트) + rem(카드) 혼용** ⭐

**선택 이유**:

- 바텀시트는 화면 크기에 비례 (60vh)
- 카드는 고정 크기 유지 (rem) - 일관된 사용자 경험

**장점**:

- 바텀시트가 화면 크기에 따라 자동 조정
- 카드 크기는 일정하게 유지되어 가독성 좋음
- 디자인 의도대로 구현 가능

**단점**:

- 매우 작은 화면(iPhone SE 등)에서 카드가 잘릴 가능성 있음
- 하지만 60vh로 충분한 여유 확보

#### 2개 카드


**시각적 결과**:

```

      │  회색 카드   │
      │  (180px)    │
      │  zIndex: 1  │
87px  ├─────────────┤ ← 겹침 시작
      │  노란 카드   │
      │  (130px)    │
      │  zIndex: 2  │ ← 앞에 보임 ✅

```

#### 3개 이상 카드

```typescript
// 첫 번째 (index 0)
height: "8.125rem";
bottom: "-5rem"; // -80px (숨김)
zIndex: totalCourses;

// 두 번째 (index 1)
height: "11.25rem";
bottom: "0"; // 기준점
zIndex: totalCourses - 1;

// 세 번째+ (index 2+)
height: "11.25rem";
bottom: "8.875rem + (index - 2) × 5.4375rem"; // 142px부터 87px씩
zIndex: totalCourses - index;
```

### 3. **스택 높이 계산** (`src/components/map/refactored-course-card-stack.tsx`)

```typescript
// 1개
return "100%"; // 스크롤 영역에 꽉 참

// 2개
return "16.6875rem"; // 5.4375rem + 11.25rem = 267px

// 3개 이상
const lastCardBottom = lastCardIndex × 5.4375;
const totalHeight = lastCardBottom + 11.25;
return `${totalHeight}rem`;
```

**⚠️ 주의**: 3개 이상일 때 계산식이 실제 레이아웃과 약간 다름

- 실제: 1번(-5rem), 2번(0), 3번(8.875rem), 4번(14.3125rem)...
- 계산: index × 5.4375 + 11.25

---

### 4. **카드 컨테이너** (`src/components/map/refactored-course-card-stack.tsx:43-45`)

```tsx
<div
  className="relative w-full font-sans mb-0 flex flex-col justify-end"
  style={{ height: stackHeight, minHeight: "100%" }}
>
```

**현재 이슈**:

- `minHeight: "100%"` 때문에 카드가 바텀시트 바닥에서 떨어질 수 있음
- 카드는 `absolute` 포지션이라 이 컨테이너가 기준점
- `justify-end`는 카드가 absolute라 영향 없음

**개선 방안** (선택사항):

```tsx
// minHeight 제거
style={{ height: stackHeight }}
```

### 5. **카드 여백** (`src/components/map/course-card.tsx:60`)

```tsx
className = "absolute left-0 right-0 px-[41px] py-[20px] cursor-pointer";
```

**현재 여백**:

- 좌우 패딩: `px-[41px]` = 41px
- 상하 패딩: `py-[20px]` = 20px

**바텀시트 여백**:

- `fixed bottom-2 left-2 right-2` = 8px (0.5rem)

**총 좌우 간격**: 41px + 8px = 49px

### 2. **3개 이상 스택 높이 계산 부정확**

**현재 계산**:

```typescript
const lastCardBottom = lastCardIndex × 5.4375;
const totalHeight = lastCardBottom + 11.25;
```

**실제 레이아웃**:

- index 0: -5rem
- index 1: 0rem
- index 2: 8.875rem
- index 3: 14.3125rem (8.875 + 5.4375)

**수정 필요**:

```typescript
// index 1이 기준점(0)이므로
const lastCardBottom = index === 0 ? -5 :
                       index === 1 ? 0 :
                       8.875 + (index - 2) × 5.4375;
```
