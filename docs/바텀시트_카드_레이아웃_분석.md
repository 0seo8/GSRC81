## 🃏 카드 개수별 레이아웃

### 1개 카드

```
┌─────────────────────┐
│     바텀시트        │
│  ┌───────────────┐  │
│  │               │  │  ← 180px 높이
│  │    카드 1     │  │  ← 전체 둥근 모서리 (45px)
│  │               │  │  ← bottom: 9px
│  └───────────────┘  │
└─────────────────────┘
```

| 항목 | 값 |
|------|-----|
| 높이 | 180px (11.25rem) |
| bottom | 9px (0.5625rem) |
| borderRadius | 전체 둥근 (45px) |
| zIndex | 1 |

---

### 2개 카드

```
┌─────────────────────┐
│     바텀시트        │
│  ┌───────────────┐  │  ← 카드 2 (index=1)
│  │   카드 2      │  │  ← bottom: 80px (5rem)
│  ├───────────────┤  │  ← 상단만 둥근
│  │               │  │
│  │   카드 1      │  │  ← 카드 1 (index=0)
│  │               │  │  ← bottom: 0px
│  └───────────────┘  │  ← 전체 둥근
└─────────────────────┘
```

| 카드 | 높이 | bottom | borderRadius | zIndex |
|------|------|--------|--------------|--------|
| 카드 1 (index=0) | 180px | 0px | 전체 둥근 | 2 (위) |
| 카드 2 (index=1) | 180px | 80px (5rem) | 상단만 둥근 | 1 (아래) |

---

### 3개 이상 카드

```
┌─────────────────────┐
│     바텀시트        │
│  ┌───────────────┐  │  ← 카드 N (마지막)
│  │   카드 N      │  │
│  ├───────────────┤  │  ← 130px 노출
│  │   카드 3      │  │  ← index=2, bottom: 80px (5rem)
│  ├───────────────┤  │  ← 130px 노출
│  │   카드 2      │  │  ← index=1, bottom: -50px
│  ├───────────────┤  │
│  │   카드 1      │▄▄│  ← index=0, 12px만 노출
└──┴───────────────┴──┘    (bottom: -124px)
```

| 카드 | 높이 | bottom | 노출 | zIndex |
|------|------|--------|------|--------|
| 카드 1 (index=0) | 180px | -124px (-7.75rem) | 12px만 | totalCourses |
| 카드 2 (index=1) | 180px | -50px (-3.125rem) | 기준점 | totalCourses - 1 |
| 카드 3+ (index=2+) | 180px | 공식 적용 | 130px | totalCourses - index |

**Bottom 계산 공식** (index=2+):
```
bottom = -50px + (index - 1) × 130px
```

| index | 계산 | bottom |
|-------|------|--------|
| 2 | -50 + 130 | 80px (5rem) |
| 3 | -50 + 260 | 210px (13.125rem) |
| 4 | -50 + 390 | 340px (21.25rem) |

## ✅ 해결된 이슈

### 바텀시트 60vh 스크롤 시 카드가 헤더에 가려지는 문제

**원인**:
- 헤더에 z-index가 없어서 스크롤 시 카드가 헤더 위로 올라감
- 카드 스택이 `minHeight`로 설정되어 스크롤 영역으로 인식되지 않음

**해결**:
1. 헤더에 고정 높이(7.5rem), z-index(10), 배경색 추가
2. 카드 스택 `minHeight` → `height`로 변경
3. 카드 영역에 `flex justify-end` 적용

## 🎯 결론

### 현재 구현 방식

1. **vh + rem 혼용**: 바텀시트는 유연하게 (60vh/95vh), 카드는 일정하게 (rem)
2. **모든 카드 180px 통일**: 일관된 레이아웃
3. **헤더 고정**: z-index로 스크롤 시 카드 가림 방지
4. **스크롤 지원**: 카드가 많으면 자연스럽게 스크롤
